Each card is one test: one chart and one sentence, sorted by strength of evidence. A low p-value is not proof, and nothing here is a cause-and-effect claim.

n = how many calls the test used. p = the chance of seeing a gap this big by luck alone if there were no real pattern (lower = less likely luck). “Could be chance” means luck explains it fine. Insights use all data and ignore the filters above.
